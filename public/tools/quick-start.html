The quick start, inside a clone.

Five steps from a clone to a question, as the protocol site’s “Build on it” gives them, read on October 4, 2026. The site says “If it takes longer, that is a bug.”

Before step 2

Run every npx command inside the cloned folder, after npm install. Nothing from this project is on npm. Outside the clone, npx kindling-validate returned a 404 from npm on October 4, 2026.

The npm name “kindling” belongs to someone else. It is an unrelated project (“Project bootstrapping with an emphasis on simplicity,” version 1.1.0). npm install kindling will not install this protocol’s tools.

The README still points at kindling.tranquiltech.com. The live sites are kindling.foundation and protocol.kindling.foundation. K.1 lists five things the repository gets wrong today.

  1. Step 1 of 5

    Clone and install

    You need git, Node.js and npm.

    $ git clone https://github.com/IntelliBotique/kindling.git
$ cd kindling
$ npm install

  2. Step 2 of 5

    Validate a Pool manifest

    kindling-validate checks a Kindling document against its schema.

    $ npx kindling-validate https://example.com/pools/queer-creatives-la

  3. Step 3 of 5

    Parse a profile URL

    kindling-parse turns a profile page into a structured parsed_profile JSON document.

    $ npx kindling-parse https://noor.example.com

  4. Step 4 of 5

    Run the starter discovery agent

    kindling-discover asks one or more Pools a question in natural language. Only people who said yes to a Pool are in it to be asked.

    $ npx kindling-discover \
  --pool https://example.com/pools/queer-creatives-la \
  --query "who is up for a hike this weekend?"

  5. Step 5 of 5

    Deploy the registry to your own infrastructure

    See registry/README.md in the repository. It is designed to run on a single VPS or a small container. A registry is one consumer of the well-known file, and anyone may run one (§8.5).

    # see registry/README.md in the repository
# designed to run on a single VPS or a small container

The commands and their descriptions are the protocol site’s, from protocol.kindling.foundation/build.html, read October 4, 2026. The example hosts are the site’s own .example addresses, and Noor is the site’s invented example person. Write your own manifest with the manifest walkthrough.
